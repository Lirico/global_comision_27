# 🚀 Desafío 01: Tu Primer Sitio Web con HTML5

## 🎯 Objetivo del Desafío
Consolidar los fundamentos del desarrollo web front-end la estructuración avanzada de HTML5 con un enrutado. Aprenderás a conectar múltiples páginas entre sí, recibir datos del usuario a través de formularios interactivos, integrar contenido multimedia nativo y utilizar iconografía moderna.

> 💡 **Nota sobre la temática:** La temática del proyecto es a elección (blog personal, tienda, hobby, película, juego, etc.).

---

## 🛠️ Requisitos Técnicos e Historias de Usuario

Tu proyecto web deberá estructurarse y desarrollarse cumpliendo con los siguientes requerimientos obligatorios:

### 1. Estructura Multipágina y Enlaces de Navegación
- Tu sitio web deberá contar obligatoriamente con al menos **dos páginas HTML conectadas entre sí**:
  - `index.html` (Página de Inicio / Portada).
  - Una segunda página temática (por ejemplo, `contacto.html`, `productos.html` o `sobre-mi.html`).
- Implementar un menú de navegación global (`<nav>`) con enlaces absolutos o relativos funcionales que permitan transicionar fluidamente entre todas las páginas del sitio.

### 2. Metadatos de SEO y Optimización (`<head>`)
El encabezado técnico de cada documento HTML debe configurarse profesionalmente incluyendo:
- Etiqueta `<title>` descriptiva y única para cada página.
- Metaetiqueta de descripción: `<meta name="description" content="Breve resumen del contenido de tu página">`.
- Metaetiqueta de palabras clave: `<meta name="keywords" content="palabra1, palabra2, palabra3">`.

### 3. Interactividad: Formularios Web (`<form>`)
En la segunda página (o sección dedicada), incorporá un formulario completo que incluya:
- Campos de texto y email (`<input type="text">`, `<input type="email">`).
- Elementos de selección o casillas (`<select>`, `<input type="checkbox">` o `<input type="radio">`).
- Área de texto para mensajes (`<textarea>`).
- Botón de envío (`<button type="submit">`).

### 4. Contenidos Avanzados y Multimedia
- **Tablas HTML:** Una tabla estructurada (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`) para organizar datos relevantes de tu temática (ej: especificaciones, precios, horarios o estadísticas).
- **Multimedia nativa:** Al menos un archivo de audio local (`<audio controls>`) y un video local o incrustado (`<video controls>`).
- **Iframes:** Un elemento `<iframe>` para embeber contenido externo relevante (por ejemplo, un mapa de ubicación o un video oficial de YouTube).

## 📋 Resumen de Requisitos Técnicos

| Categoría | Elemento / Concepto Requerido | Propósito Principal |
| :--- | :--- | :--- |
| **HTML Estructural** | `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>` | Organización semántica lógica del documento. |
| **Metadatos SEO** | `<title>`, `<meta name="description/keywords">` | Optimización para motores de búsqueda y navegadores. |
| **Navegación** | Enlaces `<a href="...">` entre páginas HTML | Estructura multipágina y conectividad fluida. |
| **Formularios & Tablas** | `<form>`, `<input>`, `<select>`, `<textarea>`, `<table>` | Captura de datos de usuarios y estructuración tabular. |
| **Multimedia & Iframes**| `<audio>`, `<video>`, `<iframe>` | Inclusión de elementos interactivos y multimedia externos. |

## 📥 Entregables y Pautas de Entrega

1. Carpeta del proyecto conteniendo los archivos HTML (`index.html` y la segunda página) y la carpeta de recursos multimedia (imágenes, audios y videos locales).
2. Compresión del proyecto en formato `.zip` o enlace al repositorio de GitHub correspondiente.
